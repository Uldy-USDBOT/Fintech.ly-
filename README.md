# Al-Khalij Investment Gateway
## fintech.ly - Premium Fintech Website

### Project Structure
```
fintech-ly/
├── index.html          # Main landing page (Home)
├── invest.html         # Investment plans & application page
├── css/
│   └── style.css       # Complete design system & styles
├── js/
│   └── main.js         # All interactive functionality
└── images/             # (Add your images here)
```

### Features
- **2 Pages**: Home + Investment Application
- **5 Service Pillars**: Stock Trading, Real Estate, Digital Assets, Wealth Protection, Smart Portfolio
- **3 Investment Plans**: Starter ($500), Growth ($2,000), Elite ($10,000/month)
- **Bilingual**: Full English/Arabic support with RTL
- **Contact**: WhatsApp integration (+218 91 888 3918)
- **Design**: Dark luxury theme with glassmorphism, particles, animations
- **Responsive**: Fully mobile-optimized
- **Performance**: Lazy loading, optimized animations, minimal dependencies

### How to Use
1. Upload all files to your web server
2. Point your domain `fintech.ly` to the folder
3. Replace placeholder images in `images/` folder
4. Update WhatsApp number in HTML if needed

### Tech Stack
- HTML5 Semantic markup
- CSS3 (Grid, Flexbox, Custom Properties, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Plus Jakarta Sans, Noto Sans Arabic)
- No frameworks, no build step required
